## Actual renderer/input fixture contract

Use the verified paired `d3d11_test_host.cpp` and `input_oracle.hpp` sources with:

```text
--composition-swapchain --noninteractive-tool-popup
```

The opt-in mode creates a real same-process `WS_VISIBLE` top-level tool popup
before the first application Present. It is kept offscreen so it cannot cover
pixel probes, uses no activation, and starts visible. The exact state file next
to the host executable is `electron-game-overlay-tool-popup-state.json`:

- `pid`, `mainHwnd`, `popupHwnd`, `visible`, actual `style`/`extendedStyle`;
- `transition` starts at zero and increases once per command;
- initial `beforeFirstPresent=true` and per-transition `foregroundUnchanged`.

The JSON is atomically replaced. Native stdout also emits
`EGO_CONTROLLED_HOST_TOOL_POPUP_V1`. After actual scene/first-key/pixel acceptance,
write one of these sibling request files and wait for a fresh state acknowledgement:

```text
electron-game-overlay-tool-popup-hide.request
electron-game-overlay-tool-popup-show.request
```

transitions. Four hide/show transitions fit the intended root-owned test. Require
