# Auxiliary popup admission regression

The console gate compares frozen generation-33 and current generation-34 headers
against ten real owned offscreen window cases, including a native tooltip. Four
auxiliary cases reproduce the old failure and preserve the current main binding.
Six genuine-peer cases keep ambiguity refusal; sole styled/frameless windows are
also tested. Foreground, token lifetime and GetLastError remain intact.

Native tooltip setup uses the documented V1 TOOLINFO fields supported by the
fixture's unmanifested common-controls API. Class names are used only to create
native fixture controls; the production predicate reads Windows style flags and
has no class/title/foreground/message heuristic.

The separate source-cache launcher checks the four-file tail over the full
26-file inventory. Actual composition pixels/input use the opt-in host mode and
marker contract documented in `doc/composition-window-eligibility.md`; those
acceptance runs remain root-owned. This console fixture never launches games or
sends keyboard/pointer input.
