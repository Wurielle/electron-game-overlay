# Owned composition and persistence contract

The console launcher runs the pinned production policy header and `ini_file.cpp`
with offscreen, nonactivating windows belonging to this fixture and its own child.
It checks exact-process selection, ambiguity, visibility, lifetime-token loss,
nonmigration and new-swapchain binding. It compiles the exact changed lifecycle
branches extracted from the pinned production swap-chain source to check initial
deferral, resize, retirement, reinitialization and unchanged ordinary branches.

The real INI cache reproduces the secondary-runtime/global TutorialProgress flush
failure under an enforced read-only sharing guard with the policy inactive. The
active owned policy succeeds without changing reserved file bytes or the guard;
foreign names and paths retain stock persistence. Native manager queries inspect
an owned child while alive and after exit with its process handle retained.

The source-cache launcher tests all eight publication boundaries and refusal of
unknown changes over the full 26-file source vector. Synthetic fixture commits
do not commit the SDK repository. No console case establishes graphics, game,
injection, actual scene rendering or physical-key acceptance.

The separate `d3d11-composition-window-routing.ps1` launcher opens the actual
DirectComposition graphics host for those acceptance runs. `-AmbiguousWindows`
opens two visible target windows and must refuse composition window inference.
